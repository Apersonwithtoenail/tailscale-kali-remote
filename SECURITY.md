# Security Policy

## Supported Versions
This is a documentation repository. There are no executable scripts to patch.

## Safe Configuration
When following this guide, **never** commit your real IP addresses, usernames, or passwords to a public repository. 

Always use placeholders in your documentation:
*   Instead of `100.89.13.7`, use `100.x.x.x`
*   Instead of your real username, use `your_username`

If you accidentally commit your private keys or real Tailscale IP, consider your machine compromised and rotate your keys immediately.
